## 무엇을 하나
"찾아 달라"는 말(가격, 살 곳, 예매처, 공식 페이지, 링크)을 작업으로 만든다(D61). 후보 페이지를 찾고, 로그인 상태가 없는 일회용 브라우저로 그 공개 페이지를
직접 열어 제목·대표 그림을 얻고, 답과 함께 링크(`report.links`)로 돌려준다. 값만 묻는 말(날씨·환율)은 이 일이 아니라 빠른 웹 검색 답(`web_lookup`)이다.
서버에서 켰을 때만 된다(`DIALOG_WEB_FIND=1`, Claude 판단과 웹 검색이 켜져 있어야 한다).

## 모델 지시
(이 기능의 지시는 코드에 있다 — 고르는 기준 `src/agent/api/cloud.py`의 `FIND_RULE`, 연 페이지를 읽고 답할 때 `src/agent/sites/public.py`의 `PUBLIC_PROMPT`.)

## 하지 않는 것
- 누르기·입력·로그인·구매·예약은 하지 않는다. 열고 읽기만 한다.
- 검색 사이트(네이버·구글 등)의 결과 화면을 브라우저로 열지 않는다(자동 접근을 금지하거나 막는다). 후보는 검색 API·웹 검색으로 찾는다.
- 로그인해야 보이는 페이지는 열지 않는다(로그인 상태를 싣지 않은 브라우저다). 사이트가 막으면 그 페이지는 건너뛴다.

## 확인된 것
- 2026-11-13 공개 물음 6개(가격 4, 운영 시간 2), 답 쓰는 방식 셋을 비교(1회씩):
  검색이 쓴 답 + 연 페이지의 링크(지금 값) 10~23초·약 $0.012·값이 맞게 나온 답 6/6 / 연 페이지를 Claude가 읽음 13~32초·$0.013·4/6(예전 가격의 글을 읽음, 공식 페이지에 값이 안 보임)
  / 연 페이지를 로컬 모델이 읽음(3개만) 36~70초·0/3.
- 링크: 한 번에 2~3개, 대표 그림 주소는 연 페이지 모두에 있었다. 공식 사이트가 이 브라우저를 막는 경우가 있었다(놀이공원 1곳) — 그때는 다른 페이지가 링크가 된다.
- 확인 못 함: 실기기에서 카드가 그려진 모양, 네이버 검색 API로 찾는 길(키가 없어 한 번도 못 돌림), 답의 사실 대조.
