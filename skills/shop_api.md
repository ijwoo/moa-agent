## 무엇을 하나
살 것을 찾는 말을 작업으로 만들어, 공식 쇼핑 검색 API로 상품을 찾고 사용자의 조건과 견줘 상품 카드(이름·가격·판매처·그림·링크)로 보여 준다(D71).
폰에도 맥에도 쇼핑 화면이 뜨지 않는다. 어느 브라우저도 쇼핑 사이트에 가지 않는다. 몇 초면 끝난다.
서버에서 켜고(`DIALOG_SHOP_API=1`) 검색 API 키(`NAVER_SEARCH_ID`·`NAVER_SEARCH_SECRET`)가 있을 때만 된다. 앱의 능력과 상관없다.

## 모델 지시
(이 기능의 지시는 코드에 있다 — 고르는 기준 `src/agent/api/cloud.py`의 `SHOP_ACTION`·`SHOP_API_NOTE`, 상품 고르기와 견준 말 `src/agent/sites/shop.py`의 `PICK_PROMPT`·`SAY_API_PROMPT`.)

## 하지 않는 것
- 배송비·옵션·도착일·재고·리뷰는 말하지 않는다(API에 없다). 카드를 눌러 상품 화면에서 확인하게 한다.
- 값을 지어 쓰지 않는다. 카드의 값은 API가 준 그대로이고, 말에 재료에 없는 숫자가 있으면 코드가 그 말을 버린다.
- 장바구니 담기·주문·결제는 하지 않는다(사용자가 카드를 눌러 직접 한다).
- 중고·단종·판매예정·렌탈·해외직구 상품은 뺀다.
- 상품 주소·그림 주소는 Claude로 보내지 않는다(카드에만 싣는다). 고르는 모델은 이름·가격·판매처만 본다.

- 2026-11-15: 합성 응답으로 단위 테스트 7개(값 정리, 실패 종류 5가지, 지어낸 숫자 버리기, 대화 연결, 주소가 Claude로 가지 않음). 고르는 판단 가상 70문장(API 길을 모든 문장에 열어 둠) 70/70.
