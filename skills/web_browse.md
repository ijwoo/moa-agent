## 무엇을 하나
정해진 기능(메일·결제내역·날씨·빠른 검색·찾기·쇼핑)에 없는 부탁 가운데 공개 사이트에서 직접 열어 보면 되는 일을 한다(일반 길, D67).
맥의 격리 브라우저(로그인 없음, 일회용)가 사이트를 열고, 검색칸에 입력하고, 누르고, 읽어서 답한다. 화면을 보고 다음 행동을 고르는 것은 Claude다.
서버에서 켰을 때만 된다(`DIALOG_WEB_BROWSE=1`, Claude 판단과 웹 검색이 켜져 있어야 한다).

## 모델 지시
(이 기능의 지시는 코드에 있다 — 고르는 기준 `src/agent/api/cloud.py`의 `BROWSE_ACTION`, 운전 규칙 `src/agent/sites/public.py`의 `BROWSE_RULES`와 `src/agent/core/loop.py`의 `SYSTEM_PROMPT`.)

## 하지 않는 것
- 로그인하지 않는다. 로그인·본인 확인 화면이 나오면 거기서 멈추고 그렇게 보고한다.
- 신청·결제·예약·주문·제출처럼 무엇을 바꾸는 버튼은 누르지 않는다. 조회·검색·보기까지만.
- 사이트가 막거나(403 등) 자동 도구를 쓰지 말라고 하면 그 사이트로 더 가지 않는다. 브라우저를 꾸미지 않는다.
- 검색 사이트(구글·네이버 등)의 화면은 열지 않는다. 어느 사이트로 갈지 모를 때는 후보 주소만 주는 검색 도구를 쓴다.
- 공개 페이지의 화면 글은 운전하는 Claude로 간다. 로그인한 화면(개인 내용)은 이 길로 다루지 않는다.

## 확인된 것
- 2026-11-14 측정(`scripts/bench_openweb.py`, 사이트가 다른 공개 과제 20개, 1회씩): haiku 운전 — 쉬운 묶음 10/10(4~27초, 과제당 $0.008 이하), 어려운 묶음 5/10.
  안 된 5개 중 4개는 사이트가 막음(기차 예매 사이트의 자동 도구 경고, 가격비교·쇼핑 403, 정부 사이트의 접속 거절), 1개는 조작 실패(sonnet 운전으로는 됨, $0.67).
  로컬 모델(qwen3:14b) 운전 — 쉬운 묶음 자동 판정 6/10, 54~606초, 지어낸 답 2건.
- 고르는 판단(가상 63문장, sonnet): 63/63 — 사이트를 짚은 부탁·조회 화면 5/5가 이 길로, 값만 묻는 말·로그인이 필요한 말·잡담은 다른 길로.
- 실제 서버 3회: 박물관 홈페이지에서 수요일 관람 시간 10초(링크 카드·캡처 포함), 이번 달 특별전 13초. 같은 과제 1회는 조작 오류로 "확인하지 못했다" → 그럴 때 검색이 쓴 답으로 대신하게 고쳤다(직접 본 것이 아니라고 밝힌다).
- 2026-11-15(D69): 브라우저를 컨테이너 안 창 모드로 바꿈 — 창 없는 모드가 403을 받던 공개 사이트 다수가 열린다(같은 10곳에서 3/10 → 10/10, 1회씩). 자동화 표시는 그대로, 막히면 멈추는 것도 그대로.
- 확인 못 함: 실기기에서의 모양, 반복했을 때의 성공률(같은 과제가 한 번은 되고 한 번은 안 됐다), 질문 카드가 뜨는 경우, 답의 사실 대조.
