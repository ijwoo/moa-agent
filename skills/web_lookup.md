## 무엇을 하나
누구나 볼 수 있는 정보(날씨, 가격, 운영 시간, 뉴스, 환율)를 묻는 말에 Claude의 웹 검색으로 찾아 답한다(D60).
대화 판단이 "찾을 일"이라고 고르면 검색할 물음 한 문장만 들고 검색하고, 답은 짧은 말풍선으로, 출처는 사이트 이름으로 마지막에 붙인다.
서버에서 Claude 판단과 웹 검색을 켰을 때만 된다(`DIALOG_HEAD=claude`, `DIALOG_WEB_SEARCH=1`) — 꺼져 있으면 이 카드는 내려가지 않는다.

## 모델 지시
(이 기능의 지시는 `src/agent/api/cloud.py`의 `WEB_ACTION`(고르는 기준)과 `WEB_PROMPT`(답 쓰는 법)에 있다. 로컬 모델은 이 일을 하지 않는다.)

## 하지 않는 것
- 로그인해야 보이는 것(내 주문·결제·메일)은 찾지 않는다. 그건 사이트 읽기·메일 기능이다.
- 찾은 곳에서 무엇을 사거나 예약하지 않는다. 읽고 알려 주기만 한다.
- 검색에는 물음 한 문장만 나간다. 대화 기록·회의 자료·읽은 결과·메일 주소는 보내지 않는다.

## 확인된 것
- 2026-11-13 고르는 판단(가상 27문장, claude-sonnet-5-5): 27/27 — 찾을 말 11/11(생략된 말을 앞 흐름으로 풀어 씀), 찾지 말아야 할 말(내 결제내역·회의 질문·잡담)에 검색 0건. 문장은 지시문과 함께 만든 것이라 독립 수치는 아니다.
- 답 쓰기(공개 물음 3개): 5.0~6.0초, 검색 1회씩, 출처 3/3, 한 번에 약 $0.05.
- 실제 서버 2회: "오늘 서울 날씨 어때?" 9.4초(판단 1.9 + 검색 7.4), 이어서 "부산은?" 6.6초 — 부산 날씨로 답함.
- 2026-11-13 답 쓰는 모델을 claude-haiku-5-5로 바꿈(사용자 결정): 공개 물음 12개 × 4회 — 12/12 답함, 중앙 3.3초, 한 번에 약 $0.012, 핵심 숫자는 매번 같음. 인용이 붙지 않은 답(8/12)은 "찾아본 곳: …"으로 적는다. 실제 서버 2회 5.5·7.9초.
- 확인 못 함: 답의 사실이 맞는지(날씨·가격을 다른 곳과 대조하지 않았다), 실기기에서의 모양, 검색이 여러 번 필요한 어려운 물음.
