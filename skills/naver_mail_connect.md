## 무엇을 하나
로그인된 에이전트 브라우저로 네이버 설정 화면을 진행한다: IMAP/SMTP 사용 확인(꺼져 있으면 승인 받고 켬) →
보안설정의 2단계 인증 관리(비밀번호 재확인은 사용자가 입력) → 승인 뒤 애플리케이션 비밀번호 생성 → 메일 계정으로 연결.
만든 비밀번호는 맥의 보안 저장소에만 둔다.

## 모델 지시
(없음 — 계정의 보안 설정을 바꾸는 일이라 모델에게 맡기지 않는다. 코드가 정해진 길을 간다.)

## 하지 않는 것
- 승인 없이 설정을 바꾸거나 비밀번호를 만들지 않는다. 기존 애플리케이션 비밀번호를 지우지 않는다.

## 확인된 것
- 2026-11-12 실제 네이버: 주소 입력 → 비밀번호 재확인 → "만들기" 승인 → 생성 → IMAP·SMTP 로그인 확인 → 연결.
- IMAP/SMTP가 꺼져 있을 때 켜는 길은 가짜 화면 테스트만(실제 계정은 이미 켜져 있었다).
