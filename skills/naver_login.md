## 무엇을 하나
에이전트 브라우저가 네이버 로그인 화면을 열고, 사용자가 앱에서 직접 로그인한다(추가 확인·2단계 인증 포함).
아이디·비밀번호는 저장하지 않고, 로그인된 상태만 맥의 보안 저장소에 둔다.

## 모델 지시
(없음 — 로그인은 모델이 하지 않는다. 코드가 화면을 읽어 사용자에게 입력·승인·선택을 넘긴다.)

## 하지 않는 것
- 로그인을 대신하지 않는다. 캡차·2단계 인증을 우회하지 않는다. 자동화 표시를 숨기지 않는다.

## 확인된 것
- 2026-11-12 실제 네이버: 추가 확인(그림 물음) → 다시 로그인 → 2단계 승인 → 로그인. 보관한 상태로 메일 화면이 열림.
- 며칠 뒤에도 로그인이 살아 있는지는 확인 못 함.
