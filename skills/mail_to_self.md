## 무엇을 하나
사용자가 맡긴 내용(회의 요약 등)을 **사용자 본인 주소로만** 실제 메일로 보낸다. 모델은 초안을 낼 뿐이고,
받는 사람 검사 → 초안 고정 → 승인 → 10초 대기(취소 가능) → 발송 → 도착 확인은 코드가 한다.

## 모델 지시
[발송] 이 작업은 사용자 본인 주소({to})로 실제 메일을 보내는 일이다. 메일 사이트를 열어 쓰지 말고 compose_mail 도구를 호출한다(to·subject·body). 본문에는 담을 내용을 직접 쓴다. 호출하면 시스템이 사용자 승인을 받아 보내고 도착을 확인한다. 보낸 뒤에는 다른 동작 없이 finish 한다. 다른 사람의 주소로는 보낼 수 없다.

## 하지 않는 것
- 이 기능은 본인 주소로만 보낸다. 남에게 보내는 메일은 다른 기능이다(`mail_to_other`, D77).
- 승인 없이 보내지 않는다. 승인한 내용과 다르면 보내지 않는다.
