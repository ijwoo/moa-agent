# 네이버 메일 연결 (본인 주소 발송, D50)

에이전트가 **내 네이버 주소로만** 메일을 보낼 수 있게 연결하는 방법. 서버는 SMTP(보내기)와 IMAP(도착 확인)을 쓴다.
아래 내용 중 네이버 쪽 화면·정책은 2026-11에 안내 글로 확인한 것이다. 실제 계정에서 다르면 이 문서를 고친다.

## 1. 네이버에서 준비
1. 네이버 메일(웹) → 환경설정 → **POP3/IMAP 설정** → "IMAP/SMTP 사용"을 **사용함**으로 저장한다.
   꺼져 있으면 비밀번호가 맞아도 로그인이 거절된다(앱에는 `auth_failed`로 보인다).
2. 네이버 계정 → 보안 설정 → **2단계 인증**을 켠다.
3. 같은 화면의 **애플리케이션 비밀번호**에서 새 비밀번호를 만든다(이 용도 전용으로 하나). 한 번만 보이므로 바로 다음 단계에 쓴다.

## 2. 앱에서 연결
앱에서 "나한테 메일 보내 줘"라고 하면 대화창에 계정 연결 화면이 뜬다(또는 내 정보 → 메일 연동). 네이버 주소와 **앱 비밀번호**를 넣으면
맥이 로그인을 확인한 뒤 비밀번호를 보관하고 그 주소를 내 주소로 등록한다. 일반 로그인 비밀번호로는 연결되지 않는다.
먼저 연결한 계정이 기본 계정("나한테")이다.

(선택) 맥에서 직접 하려면: `.env`의 `SEND_SELF_ADDRESSES`에 주소를 적고 서버를 다시 띄운 뒤, 터미널 입력 창에 앱 비밀번호를 넣는다.
```sh
security add-generic-password -U -s local-ai-agent.mail -a <내 네이버 주소> -w
```

## 서버가 쓰는 값
- 보내기: `smtp.naver.com` 465(SSL), 안 되면 587(STARTTLS). 도착 확인: `imap.naver.com` 993.
- 도착 확인은 폴더 이름을 고정하지 않는다. 받은편지함을 먼저 보고, 보낸편지함(`\Sent` 표시)이 아닌 다른 폴더에서 찾아도
  도착으로 본다(네이버는 나에게 보낸 메일을 '내게쓴메일함'에 넣을 수 있다). 보낸편지함에서만 보이면 "접수됨, 도착 확인 못 함".

## 문제가 생기면
- 앱에 "로그인하지 못했어요": IMAP/SMTP "사용함" 여부, 앱 비밀번호를 다시 만들어 연결.
- 비밀번호를 없애려면: 네이버 보안 설정에서 그 애플리케이션 비밀번호를 삭제(가장 확실), 맥에서는 앱의 연결 해제 또는
  `security delete-generic-password -s local-ai-agent.mail -a <주소>`.
- 알려 둘 점: 앱 비밀번호는 "나에게 보내기"만 되는 키가 아니라 그 계정의 메일 전체를 읽고 보낼 수 있다. 본인 주소로만 보내는 제한은 서버 코드가 지킨다.
