# Gmail 연결 (본인 주소 발송, D50)

에이전트가 **내 Gmail 주소로만** 메일을 보낼 수 있게 연결하는 방법. 서버는 SMTP(보내기)와 IMAP(도착 확인)을 쓴다.
구글 쪽 화면·정책은 2026-11에 안내 글로 확인한 것이다. 실제 계정에서 다르면 이 문서를 고친다.

## 1. 구글에서 준비
1. Google 계정 → 보안 → **2단계 인증**을 켠다.
2. Google 계정 → 보안 → **앱 비밀번호**에서 새 비밀번호를 만든다(이 용도 전용으로 하나, 이름은 자유). 16자가 4자씩 띄어 보인다.
   띄어쓰기는 넣어도 되고 빼도 된다(서버가 뺀다).
3. Gmail 설정 → 전달 및 POP/IMAP에서 IMAP이 켜져 있는지 확인한다(계정에 따라 항상 켜져 있어 항목이 없을 수 있다).

## 2. 앱에서 연결
앱에서 "지메일로 나한테 보내 줘"라고 하면 대화창에 계정 연결 화면이 뜬다(또는 내 정보 → 메일 연동). Gmail 주소와 **앱 비밀번호**를 넣으면
맥이 로그인을 확인한 뒤 비밀번호를 보관하고 그 주소를 내 주소로 등록한다. 일반 로그인 비밀번호로는 연결되지 않는다.

(선택) 맥에서 직접 하려면: `.env`의 `SEND_SELF_ADDRESSES`에 주소를 적고 서버를 다시 띄운 뒤, 터미널 입력 창에 앱 비밀번호를 넣는다.
```sh
security add-generic-password -U -s local-ai-agent.mail -a <내 Gmail 주소> -w
```

## 서버가 쓰는 값
- 보내기: `smtp.gmail.com` 465(SSL), 안 되면 587(STARTTLS). 도착 확인: `imap.gmail.com` 993.
- 도착 확인: 받은편지함에서 보낸 메일의 Message-ID를 찾아 본문을 대조한다. 보낸편지함(`\Sent`)에서만 보이면 "접수됨, 도착 확인 못 함".
- Gmail API(OAuth)는 쓰지 않는다(동의 화면·토큰 갱신이 필요하고 테스트 상태의 토큰은 7일 뒤 만료된다는 안내).

## 문제가 생기면
- 앱에 "로그인하지 못했어요": 앱 비밀번호를 새로 만들어 다시 연결. 회사·학교 계정은 관리자가 앱 비밀번호를 막았을 수 있다.
- 비밀번호를 없애려면: Google 계정의 앱 비밀번호 목록에서 삭제(가장 확실), 맥에서는 앱의 연결 해제 또는
  `security delete-generic-password -s local-ai-agent.mail -a <주소>`.
- 알려 둘 점: 앱 비밀번호는 그 계정의 메일 전체를 읽고 보낼 수 있다. 본인 주소로만 보내는 제한은 서버 코드가 지킨다.
